SMARTPARK REAL-TIME PROJECT
1) Install Python 3.10 or newer.
2) Open terminal in this folder.
3) Create/activate a virtual environment.
4) Run: pip install -r requirements.txt
5) Run: flask --app app init-db
6) Run: python app.py
7) Visit: http://127.0.0.1:5000
8) Register a customer account. Admin dashboard: /admin (admin account seeded during init-db).
See README.md for PostgreSQL, Render deployment, database and real-time details.
